## 1. The Magic Hexagon for Trigonometry

The **Magic Hexagon** is a spatial memory tool used to instantly recall trigonometric identities, derivatives, and integrations without rote memorization.

### Setup and Construction
1. Draw a standard **hexagon**.
2. Place a **1** exactly in the center.
3. Label the vertices starting from the far-left and moving clockwise or using these rules:
   * **All "C" functions** ($\cos, \cot, \csc$) always go on the **right side**.
   * $\tan$ sits on the far-left vertex.
   * Use the quotient identity ($\tan\theta = \frac{\sin\theta}{\cos\theta}$) to place $\sin$ and $\cos$ sequentially along the top.
   * Opposite vertices are reciprocals ($\tan \leftrightarrow \cot$, $\sin \leftrightarrow \csc$, $\cos \leftrightarrow \sec$).

### Magic Hexagon Navigation Rules

| Category / Identity Type | Hexagon Traversal Rule | Mathematical Examples |
| :--- | :--- | :--- |
| **Quotient Identities** | Any vertex equals the next vertex divided by the one after it (clockwise or counter-clockwise). | $\tan\theta = \frac{\sin\theta}{\cos\theta}$ <br> $\cot\theta = \frac{\csc\theta}{\sec\theta}$ |
| **Product Identities** | Any vertex equals the product of its two immediate neighboring vertices. | $\sin\theta = \tan\theta \cdot \cos\theta$ <br> $1 = \sin\theta \cdot \csc\theta$ (opposite vertices product) |
| **Pythagorean Identities** | For the three upper-facing triangles: the sum of the squares of the top two vertices equals the square of the bottom vertex. | $\sin^2\theta + \cos^2\theta = 1^2$ <br> $\tan^2\theta + 1^2 = \sec^2\theta$ <br> $1^2 + \cot^2\theta = \csc^2\theta$ |
| **Co-Function Identities** | Horizontal parallel vertices are co-functions across complementary angles $(\frac{\pi}{2} - \theta)$. | $\sin\theta = \cos\left(\frac{\pi}{2} - \theta\right)$ <br> $\tan\theta = \cot\left(\frac{\pi}{2} - \theta\right)$ |

## 2. Limits, Continuity & Foundations

| Category | Reference Formulas & Theorems | Core Operational Application |
| :--- | :--- | :--- |
| **Limit Definition** | $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$ | Evaluates the exact slope of a tangent line at a given point by shrinking a secant interval to zero. |
| **Indeterminate Forms** | Check for formats: $\frac{0}{0}$, $\frac{\infty}{\infty}$, $0 \cdot \infty$, $\infty - \infty$, $0^0$, $1^\infty$, $\infty^0$ | Triggers algebraic simplification, rationalization, or advanced calculus methods. |
| **L'Hôpital's Rule** | If $\lim_{x \to c} \frac{f(x)}{g(x)} = \frac{0}{0}$ or $\frac{\pm\infty}{\pm\infty}$ <br> Then $\lim_{x \to c} \frac{f(x)}{g(x)} = \lim_{x \to c} \frac{f'(x)}{g'(x)}$ | Differentiate the numerator and denominator independently. **Do not use the quotient rule here.** |
| **Squeeze Theorem** | If $g(x) \le f(x) \le h(x)$ for all $x \ne c$ near $c$, <br> and $\lim_{x \to c} g(x) = \lim_{x \to c} h(x) = L$, then $\lim_{x \to c} f(x) = L$ | Used for complex sandwich limits like $\lim_{x \to 0} x^2 \sin(\frac{1}{x}) = 0$. |
| **Continuity Condition** | $f(x)$ is continuous at $x = c$ if and only if: <br> 1. $f(c)$ is defined <br> 2. $\lim_{x \to c} f(x)$ exists <br> 3. $\lim_{x \to c} f(x) = f(c)$ | Verifies if an engineering function has breaks, holes, jumps, or vertical asymptotes. |
| **Intermediate Value Theorem (IVT)** | If $f(x)$ is continuous on $[a,b]$ and $N$ is between $f(a)$ and $f(b)$, there exists a $c \in (a,b)$ such that $f(c) = N$. | Proves the existence of roots/zeros ($N=0$) when a function changes sign from positive to negative. |

## Quick-Reference Formulas

### 1. Limits

lim(x→c) f(x) = L means f(x) gets as close to L as you want when x is close enough to c (x ≠ c). The value of f(c) itself doesn't matter.

To evaluate a limit:

1. Substitute directly. If you get a real number, you're done.
2. If you get 0/0, simplify: factor and cancel, multiply by the conjugate, or combine fractions.
3. If you get k/0 with k ≠ 0, the limit is ±∞ or doesn't exist. Check both one-sided limits.
4. If you still have 0/0 or ∞/∞, use L'Hôpital's Rule (topic 7).

Example 1 (factoring): lim(x→3) (x² − 9)/(x − 3)

- Substitution gives 0/0.
- Factor: (x − 3)(x + 3)/(x − 3) = x + 3 for x ≠ 3.
- The limit is 6.

Example 2 (rationalizing): lim(x→0) (√(x + 4) − 2)/x

- Multiply the top and bottom by √(x + 4) + 2. The numerator becomes (x + 4) − 4 = x.
- The expression becomes 1/(√(x + 4) + 2).
- The limit is 1/4.

One-sided limits: a limit exists only if the left and right limits both exist and are equal. For |x|/x at x = 0, the left limit is −1 and the right limit is 1, so the limit doesn't exist.

Limits at infinity for rational functions. Compare the degree of the numerator (n) with the degree of the denominator (m):

- If n < m, the limit is 0.
- If n = m, the limit is the ratio of the leading coefficients. Example: lim(x→∞) (3x² − x)/(5x² + 2) = 3/5.
- If n > m, the limit is ±∞, so there's no finite limit.

Special limits (x in radians):

- lim(x→0) sin x / x = 1
- lim(x→0) (1 − cos x)/x = 0
- lim(x→0) sin(kx)/x = k. For example, sin 3x / x → 3.
- lim(x→∞) (1 + 1/x)ˣ = e
- lim(x→∞) (1 + k/x)ˣ = eᵏ

### 2. Continuity

The three conditions for continuity are in the Quick-Reference. There are three types of discontinuity:

- Removable: the limit exists, but f(c) is missing or has a different value. For example, (x² − 1)/(x − 1) at x = 1 has limit 2, but f(1) is undefined. Defining f(1) = 2 fixes it.
- Jump: both one-sided limits exist, but they differ. Examples are |x|/x at 0 and step functions.
- Infinite: there's a vertical asymptote, as with 1/x at x = 0.

Polynomials are continuous everywhere. Rational functions are continuous everywhere except where the denominator is 0.

### 3. The derivative

f′(x) is the slope of the tangent line, or the instantaneous rate of change. Other notations are y′, dy/dx and Df(x).

Example 3 (from the definition): f(x) = x²

- [f(x + h) − f(x)]/h = [(x + h)² − x²]/h = (2xh + h²)/h = 2x + h
- As h → 0, this gives f′(x) = 2x.

If f is differentiable at a point, it's continuous there. The reverse doesn't always hold: |x| is continuous at 0, but it has a corner there, so it has no derivative at 0.

### 4. Derivative formulas

Here u is a function of x, and u′ = du/dx. Leaving out the ·u′ factor is the most common mistake with these formulas.

Basic formulas:

- d/dx (c) = 0
- d/dx (xⁿ) = n·xⁿ⁻¹
- d/dx (uⁿ) = n·uⁿ⁻¹·u′
- d/dx (√u) = u′/(2√u)

Exponential and logarithmic:

- d/dx (eᵘ) = eᵘ·u′
- d/dx (aᵘ) = aᵘ·ln a·u′
- d/dx (ln u) = u′/u
- d/dx (logₐ u) = u′/(u·ln a)

Trigonometric (radians only):

- d/dx (sin u) = cos u·u′
- d/dx (cos u) = −sin u·u′
- d/dx (tan u) = sec² u·u′
- d/dx (cot u) = −csc² u·u′
- d/dx (sec u) = sec u·tan u·u′
- d/dx (csc u) = −csc u·cot u·u′
- To remember the signs: the derivatives of the "co" functions (cos, cot, csc) all start with a minus sign.

Inverse trigonometric:

- d/dx (sin⁻¹ u) = u′/√(1 − u²)
- d/dx (cos⁻¹ u) = −u′/√(1 − u²)
- d/dx (tan⁻¹ u) = u′/(1 + u²)
- d/dx (cot⁻¹ u) = −u′/(1 + u²)
- d/dx (sec⁻¹ u) = u′/(|u|·√(u² − 1))
- d/dx (csc⁻¹ u) = −u′/(|u|·√(u² − 1))
- Some textbooks define the range of sec⁻¹ so that the absolute value drops out. Follow your instructor's version.

Hyperbolic (if your syllabus covers it):

- d/dx (sinh u) = cosh u·u′
- d/dx (cosh u) = sinh u·u′
- d/dx (tanh u) = sech² u·u′

### 5. Chain rule, implicit, logarithmic, higher-order and parametric derivatives

Example 4 (chain rule): y = sin³(x² + 1)

- Work from the outside in: first the cube, then sin, then x² + 1.
- y′ = 3 sin²(x² + 1) · cos(x² + 1) · 2x = 6x sin²(x² + 1) cos(x² + 1)

Example 5 (implicit): x² + y² = 25

- Differentiate both sides: 2x + 2y·y′ = 0, so y′ = −x/y.
- At (3, 4), the slope is −3/4.

Example 6 (implicit, harder): x³ + y³ = 6xy

- Differentiate both sides: 3x² + 3y²·y′ = 6y + 6x·y′
- Collect the y′ terms: y′(3y² − 6x) = 6y − 3x²
- Solve: y′ = (2y − x²)/(y² − 2x)

Example 7 (logarithmic): y = xˣ, x > 0

- Take ln of both sides: ln y = x ln x
- Differentiate: y′/y = ln x + 1
- Solve: y′ = xˣ(ln x + 1)

Higher derivatives: y″ = d²y/dx². For an implicit function, differentiate y′ again, then substitute the y′ you already found.

Parametric derivatives: if x = f(t) and y = g(t), then

- dy/dx = (dy/dt)/(dx/dt)
- d²y/dx² = [d/dt (dy/dx)]/(dx/dt)

Dividing d²y/dt² by d²x/dt² does not give d²y/dx².

Example 8 (parametric): x = t², y = t³

- dy/dx = 3t²/(2t) = 3t/2
- d²y/dx² = (3/2)/(2t) = 3/(4t)

### 6. Tangent and normal lines

- Tangent line at (x₁, y₁): y − y₁ = m(x − x₁), where m = f′(x₁).
- Normal line: it has slope −1/m. If m = 0, the normal is the vertical line x = x₁.

Example 9: y = x³ − 2x at x = 1

- The point is (1, −1), since y(1) = −1.
- y′ = 3x² − 2, so the slope is m = 1.
- Tangent line: y = x − 2
- Normal line: y = −x

### 7. L'Hôpital's Rule and indeterminate forms

The rule only works on 0/0 or ∞/∞, so check the form before every use. Differentiate the top and bottom separately instead of using the quotient rule.

Example 10: lim(x→0) (eˣ − 1 − x)/x²

- The form is 0/0. One application gives (eˣ − 1)/(2x).
- That's still 0/0. A second application gives eˣ/2.
- The limit is 1/2.

Other indeterminate forms need rewriting first:

- 0·∞: rewrite f·g as f/(1/g).
- ∞ − ∞: combine into one fraction.
- 0⁰, 1^∞ and ∞⁰: let y be the expression and find lim ln y = L. The answer is e^L.

Example 11: lim(x→0⁺) xˣ

- ln y = x ln x = ln x/(1/x), which has the form ∞/∞.
- L'Hôpital gives (1/x)/(−1/x²) = −x → 0.
- The answer is e⁰ = 1.

Example 12: lim(x→∞) (1 + 2/x)ˣ

- ln y = ln(1 + 2/x)/(1/x), which has the form 0/0.
- L'Hôpital gives 2/(1 + 2/x) → 2.
- The answer is e².

### 8. Rolle's Theorem and the Mean Value Theorem

Mean Value Theorem: if f is continuous on [a, b] and differentiable on (a, b), then some c in (a, b) has f′(c) = [f(b) − f(a)]/(b − a).

Rolle's Theorem is the special case where f(a) = f(b), so f′(c) = 0.

Example 13:

- f(x) = x² on [1, 3]: the average slope is (9 − 1)/2 = 4. Solving 2c = 4 gives c = 2.
- f(x) = x² − 4x + 3 on [1, 3]: f(1) = f(3) = 0. Solving 2c − 4 = 0 gives c = 2.

### 9. Curve sketching

Steps:

1. Find the domain, intercepts, symmetry and asymptotes.
2. Find f′. The critical numbers are the points in the domain where f′ = 0 or f′ is undefined. Use a sign chart to see where f increases and decreases.
3. First Derivative Test: if f′ changes from + to −, there's a local max. If it changes from − to +, there's a local min.
4. Find f″. The graph is concave up where f″ > 0 and concave down where f″ < 0. An inflection point is where the concavity changes and f is defined.
5. Second Derivative Test: if f′(c) = 0 and f″(c) < 0, there's a local max. If f″(c) > 0, there's a local min. If f″(c) = 0, the test fails, so use the first derivative test.

Example 14: f(x) = x³ − 3x

- f′ = 3(x − 1)(x + 1), so the critical numbers are x = ±1.
- f increases on (−∞, −1) and (1, ∞), and decreases on (−1, 1).
- There's a local max at (−1, 2) and a local min at (1, −2).
- f″ = 6x, so the graph is concave down for x < 0 and concave up for x > 0. The inflection point is (0, 0).
- The x-intercepts are 0 and ±√3, and the graph is symmetric about the origin.

## 1. Limits & L'Hôpital's Rule Example

### Problem
Evaluate the limit:
$$\lim_{x \to 0} \frac{\sin(4x)}{x^2 + 2x}$$

### Solution
1. **Check for Indeterminate Form**: Substitute $x = 0$ into the expression.
   $$\frac{\sin(4 \cdot 0)}{0^2 + 2(0)} = \frac{0}{0}$$
   Because the limit yields a $\frac{0}{0}$ indeterminate form, **L'Hôpital's Rule** applies.

2. **Differentiate Numerator and Denominator Independently**:
   * Numerator: $\frac{d}{dx}[\sin(4x)] = 4\cos(4x)$ *(via Chain Rule)*
   * Denominator: $\frac{d}{dx}[x^2 + 2x] = 2x + 2$

3. **Re-evaluate the Limit**:
   $$\lim_{x \to 0} \frac{4\cos(4x)}{2x + 2}$$
   Substitute $x = 0$ into the new expression:
   $$\frac{4\cos(0)}{2(0) + 2} = \frac{4(1)}{2} = \mathbf{2}$$

## 2. Related Rates Example (Mechanical Design)

### Problem
A hydraulic piston compresses oil inside a cylindrical chamber. The radius of the cylinder is fixed at **$0.05\text{ m}$**. If the piston pushes downward, decreasing the height of the fluid volume at a rate of **$0.2\text{ m/s}$**, how fast is the volume of the oil changing?

### Solution
1. **Identify Given Information & Rates**:
   * Constant radius: $r = 0.05\text{ m} \implies \frac{dr}{dt} = 0$
   * Rate of change of height: $\frac{dh}{dt} = -0.2\text{ m/s}$ *(negative because height is decreasing)*
   * Target rate: Find $\frac{dV}{dt}$

2. **Set Up the Geometric Model**:
   The volume $V$ of a cylinder is given by:
   $$V = \pi r^2 h$$

3. **Differentiate with Respect to Time ($t$)**:
   Since $r$ is a constant, treat $\pi r^2$ as a constant coefficient:
   $$\frac{dV}{dt} = \pi r^2 \frac{dh}{dt}$$

4. **Substitute and Solve**:
   $$\frac{dV}{dt} = \pi (0.05)^2 (-0.2)$$
   $$\frac{dV}{dt} = \pi (0.0025) (-0.2) = -0.0005\pi \approx \mathbf{-0.00157\text{ m}^3\text{/s}}$$

The volume of the fluid is decreasing at a rate of **$0.00157\text{ m}^3\text{/s}$**.

## 3. Optimization Example (Material Minimization)

### Problem
A manufacturing engineer needs to design a cylindrical storage tank that can hold exactly **$16\pi\text{ m}^3$** of liquid. To minimize the cost of sheet metal, what dimensions (radius $r$ and height $h$) will minimize the total surface area of the tank? *(Assume a closed top).*

### Solution
1. **Set Up Constraints & Target Equation**:
   * Fixed Volume Constraint: $V = \pi r^2 h = 16\pi \implies h = \frac{16}{r^2}$
   * Minimization Target (Surface Area): $A = 2\pi r^2 + 2\pi r h$

2. **Express Surface Area in Terms of One Variable**:
   Substitute the constraint for $h$ into the area equation:
   $$A(r) = 2\pi r^2 + 2\pi r \left(\frac{16}{r^2}\right)$$
   $$A(r) = 2\pi r^2 + \frac{32\pi}{r} = 2\pi r^2 + 32\pi r^{-1}$$

3. **Find the Critical Points ($A'(r) = 0$)**:
   Take the derivative with respect to $r$:
   $$A'(r) = 4\pi r - 32\pi r^{-2} = 4\pi r - \frac{32\pi}{r^2}$$
   Set the derivative to zero to optimize:
   $$4\pi r = \frac{32\pi}{r^2}$$
   $$4\pi r^3 = 32\pi \implies r^3 = 8 \implies \mathbf{r = 2\text{ m}}$$

4. **Verify it is a Minimum**:
   Find the second derivative:
   $$A''(r) = 4\pi + \frac{64\pi}{r^3}$$
   Plugging in $r = 2$ yields $A''(2) = 4\pi + 8\pi = 12\pi$. Since $A''(2) > 0$, this point marks an absolute minimum.

5. **Calculate the Height**:
   $$h = \frac{16}{(2)^2} = \mathbf{4\text{ m}}$$

The optimal tank dimensions are a radius of **$2\text{ m}$** and a height of **$4\text{ m}$**.

## 4. Implicit Differentiation Example

### Problem
An elliptical structural linkage profile follows the curve equation $2x^2 + 3y^2 = 14$. Find the slope of the tangent line ($\frac{dy}{dx}$) along this linkage at the specific coordinate boundary point **$(1, 2)$**.

### Solution
1. **Differentiate implicitly with respect to $x$**:
   Apply the power rule to each term. Remember to multiply by $\frac{dy}{dx}$ whenever differentiating a $y$ term due to the chain rule.
   $$\frac{d}{dx}[2x^2] + \frac{d}{dx}[3y^2] = \frac{d}{dx}[14]$$
   $$4x + 6y\left(\frac{dy}{dx}\right) = 0$$

2. **Isolate $\frac{dy}{dx}$**:
   $$6y\left(\frac{dy}{dx}\right) = -4x$$
   $$\frac{dy}{dx} = -\frac{4x}{6y} = -\frac{2x}{3y}$$

3. **Evaluate at the coordinate $(1, 2)$**:
   $$\frac{dy}{dx}\bigg|_{(1,2)} = -\frac{2(1)}{3(2)} = \mathbf{-\frac{1}{3}}$$

The geometric slope of the linkage at that exact physical point is **$-\frac{1}{3}$**.
