# Thermodynamics II

## Quick-reference Formulas

## Gas Power Cycles

| Category | Reference Formulas & Relations |
| :--- | :--- |
| **Otto Cycle** | Compression Ratio: $r = \frac{V_1}{V_2}$ <br> Thermal Efficiency: $\eta_{\text{th, Otto}} = 1 - \frac{1}{r^{k-1}}$ |
| **Diesel Cycle** | Cutoff Ratio: $r_c = \frac{V_3}{V_2}$ <br> Thermal Efficiency: $\eta_{\text{th, Diesel}} = 1 - \frac{1}{r^{k-1}} \left[ \frac{r_c^k - 1}{k(r_c - 1)} \right]$ |
| **Brayton Cycle** | Pressure Ratio: $r_p = \frac{P_2}{P_1}$ <br> Thermal Efficiency: $\eta_{\text{th, Brayton}} = 1 - \frac{1}{r_p^{(k-1)/k}}$ <br> Back Work Ratio: $\text{BWR} = \frac{w_{\text{comp,in}}}{w_{\text{turb,out}}}$ |

## Vapor Power & Refrigeration Cycles

| Category | Reference Formulas & Relations |
| :--- | :--- |
| **Rankine Cycle** | Pump Work: $w_{\text{pump,in}} = v_1(P_2 - P_1) = h_2 - h_1$ <br> Turbine Work: $w_{\text{turb,out}} = h_3 - h_4$ <br> Thermal Efficiency: $\eta_{\text{th}} = \frac{w_{\text{net,out}}}{q_{\text{in}}} = 1 - \frac{q_{\text{out}}}{q_{\text{in}}}$ |
| **Vapor-Compression** | Refrigerator COP: $\text{COP}_{\text{R}} = \frac{q_L}{w_{\text{net,in}}} = \frac{h_1 - h_4}{h_2 - h_1}$ <br> Heat Pump COP: $\text{COP}_{\text{HP}} = \frac{q_H}{w_{\text{net,in}}} = \frac{h_2 - h_3}{h_2 - h_1}$ |

## Gas Mixtures & Psychrometrics

| Category | Reference Formulas & Relations |
| :--- | :--- |
| **Amagat & Dalton** | Total Pressure: $P = \sum P_i$ where $P_i = y_i P$ <br> Component Mass Fraction: $\text{mf}_i = \frac{m_i}{m_m}$ <br> Component Mole Fraction: $y_i = \frac{n_i}{n_m}$ |
| **Psychrometrics** | Relative Humidity: $\phi = \frac{P_v}{P_g @ T}$ <br> Specific Humidity: $\omega = 0.622 \frac{P_v}{P - P_v}$ <br> Total Enthalpy: $H = H_a + H_v = m_a h_a + m_v h_v$ |

## Thermodynamic Property Relations

| Category | Reference Formulas & Relations |
| :--- | :--- |
| **Maxwell Relations** | $\left(\frac{\partial T}{\partial V}\right)_s = -\left(\frac{\partial P}{\partial S}\right)_v$ <br> $\left(\frac{\partial T}{\partial P}\right)_s = \left(\frac{\partial V}{\partial S}\right)_p$ <br> $\left(\frac{\partial P}{\partial T}\right)_v = \left(\frac{\partial S}{\partial V}\right)_t$ <br> $\left(\frac{\partial V}{\partial T}\right)_p = -\left(\frac{\partial S}{\partial P}\right)_t$ |
| **Clapeyron Equation**| $\left(\frac{dP}{dT}\right)_{\text{sat}} = \frac{h_{fg}}{T \cdot v_{fg}}$ <br> Clausius-Clapeyron: $\ln\left(\frac{P_2}{P_1}\right) \cong \frac{h_{fg}}{R}\left(\frac{1}{T_1} - \frac{1}{T_2}\right)$ |
